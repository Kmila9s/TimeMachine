# Security policy / Política de seguridad

**English.** Please do not open public issues for security problems. Email **daniel.ulrich@kmila.com.mx** with a description and steps to reproduce. You will get an answer within 7 days. Kmila runs locally and sends no telemetry; the most relevant areas are the web head (Blazor Server, Docker) and project import.

**Español.** No abras issues públicos para problemas de seguridad. Escribe a **daniel.ulrich@kmila.com.mx** con la descripción y los pasos para reproducirlo. Recibirás respuesta en un máximo de 7 días. Kmila corre localmente y no envía telemetría; las áreas más relevantes son la cabeza web (Blazor Server, Docker) y la importación de proyectos.
